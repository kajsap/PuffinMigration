# Puffin Migration Visualisation 

An interactive Python project for visualisation the migration patterns of Atlantic puffins from high Arctic Greenland 

# Features 

The features of this project are:

- Visualise puffin migration routes on an interactive map 
- Allow users to select technologies to select chosen puffins using a checkbox 
- Using a timeline to display the locations of selected puffins 
- Calculate statistics about the tracking data 
- Popups containing information about the tracking information 

# Technologies Used 

- Python 
- Pandas
- Folium 
- JavaScript 
- HTML 

# How to Use the Map

Once the map is open:

1) Select the puffins using the checkbox panel 
2) Play the timeline to show the puffin's movement over time
3) Click on tracking points to view additional information

# How to Use

Clone this repository: git clone https://github.com/kajsap/PuffinMigration.git

Install folium: pip install pandas folium
